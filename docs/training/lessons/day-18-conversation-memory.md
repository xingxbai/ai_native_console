# Day 18：Sliding Window 与 Summary Memory

日期：2026-11-04。状态：**IN_PROGRESS**。前置：Day 17 的粗估预算。本课只让“文本问答”带历史；工具、结构化分析和可视化仍为单轮。当前无持久会话或登录身份。

## 1. 真实场景与流程

用户先问“React 的闭包陷阱是什么？”，再问“给我一个例子”。第二句需要第一轮语境。浏览器只提交**已完成**的文本问答对；Fastify 保留最近最多四对，早期问答由 DeepSeek 压成不超过 120 字的语境摘要，再发送近期问答和当前问题。摘要只帮助理解代词和目标，不能作为订单状态等业务事实来源。

流程：`已完成记录 → 严格请求契约 → 从最新轮次向前保留完整问答对 → 旧对话生成短摘要 → system 规则 + 摘要 + 近期问答 + 当前问题 → SSE 回答`。历史由浏览器提交，服务端必须按不可信输入看待；关闭页面后历史消失。

## 2. 重点代码

`apps/web/app/ask-panel.tsx` 只取成功完成且答案不超过 1000 字的文本轮次，最多 24 对；过长答案整对跳过，不截断成半个答案。失败片段、取消回复和工具结果不进入历史。`packages/contracts/src/index.ts` 对每对的问答长度和总对数做严格校验。

`apps/api/src/conversation-memory.ts` 的关键循环：

```ts
for (const turn of [...history].reverse()) {
  const cost = Math.ceil(Array.from(turn.question).length / 2) + Math.ceil(Array.from(turn.answer).length / 2);
  if (recent.length >= 4 || used + cost > budget) break;
  recent.unshift(turn);
  used += cost;
}
return { recent, older: history.slice(0, history.length - recent.length) };
```

`apps/api/src/model-provider.ts` 只在 `older` 非空时额外调用一次 `generateText` 摘要，把旧对话截到最多 3000 字符、摘要输出限 200 token，且只有正常完成的摘要才参与本轮请求。近期轮次作为 `user/assistant` 成对消息进入 `streamText`；system 规则仍由服务端提供，当前问题放在最后。摘要每次请求重新生成，尚未持久化或复用，长会话会增加延迟和费用。

本课不把工具调用历史带入模型，因此不存在“只保留 tool call、不保留 tool result”的半组消息；未来若扩展工具多轮，必须按完整工具交互组裁剪。

## 4. 本课专项五大深水坑

| 风险 | 触发、表现、原因 | 处理与验证 |
| --- | --- | --- |
| 把半截回复写入历史 | 网络断开后仍把流中片段当完整答案 | 前端只选 `complete`；检查取消/错误记录不进入请求体。 |

手动验收：文本模式先问“React useEffect 闭包陷阱是什么？”，完成后追问“给我一个简单例子”，确认后者正确指代前者；在 Network 检查第二次请求有一对 `history`。再取消一轮，确认后续请求的 `history` 不含取消片段。连续完成 6 轮后，服务端应走摘要调用；记录额外延迟和用量。工具模式提问时请求不携带历史。

## 6. 模拟面试

**Q1：Sliding Window 为什么按完整消息组裁剪？** 推荐回答：问题和回答是一组，拆开会产生无来源答案或无回答问题；本课从最新一对往前保留最多四对，工具调用还未进入历史。追问：将来工具调用怎么办？回答：调用、结果及相关消息必须成组保留。错误答案：“只留最后四条消息”，可能恰好切断配对。

**Q2：摘要记忆和数据库事实有何区别？** 推荐回答：摘要是模型压缩的旧对话语境，可能遗漏或过时；订单状态必须重新查业务工具。本课摘要明确标为未经核验。追问：旧摘要说待退款、工具说已完成，信谁？回答：以当前授权查询的工具结果为准。错误答案：“摘要是 AI 已经验证的事实”，它并未查当前数据。

**Q3：当前实现能跨页面、跨设备恢复会话吗？** 推荐回答：不能。历史只在本页 React 状态中，由浏览器每次提交最近最多 24 对；无服务端会话存储、owner/tenant 隔离或持久摘要。追问：为何不直接把全部历史交给模型？回答：输入成本随轮次增长，还可能超窗口；目前先做成对窗口和短摘要。错误答案：“有 history 字段就有持久记忆”，请求字段不等于存储。
