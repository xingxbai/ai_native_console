## Day 01：仓库体检与最小全栈骨架

完整口头答案、追问回答和错误答案分析见 [Day 01 课件](lessons/day-01-repository-bootstrap.md)。以下是复习索引。

| 题目 | 关键回答 | 追问 |
| --- | --- | --- |
| 为什么先搭可运行骨架而不是直接写 Agent？ | 先固定环境、前后端边界和测试，便于后续定位 HTTP、模型与工具故障；目前只验证静态页和 health。 | health 200 能证明模型/数据库可用吗？不能。 |
| 浏览器与 Node API 各负责什么？ | 浏览器交互展示；服务端承担未来密钥、校验、鉴权与敏感工具，模型无权扩大权限。 | 为什么 Key 不能放 `NEXT_PUBLIC_`？它会暴露给浏览器。 |
| 怎样审查 AI Coding 生成的脚手架？ | 先读现有文件与规则，再查依赖、秘密、失败路径；跑 lint/typecheck/test/build，最后真实请求。 | 四项命令全绿还需手动看页面吗？需要，运行和视觉风险未被完全覆盖。 |

**证据边界：** Day 01 本轮锁文件安装、lint、类型检查、3/3 API 测试、构建、Web/API HTTP 200 与两个 404 已执行。模型、Agent、权限、审批、流式响应和生产环境均未实现。不要把个人学习项目说成企业上线经历。
